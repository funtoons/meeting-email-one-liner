## How it works

`main.py` writes a single fixed line of plain text to `/output/entry.txt`
— one joke about a meeting that should have been an email, 103 characters,
one line, no trailing newline. The program is
deterministic and offline: no randomness, no network, no clock, no input.
Running it twice produces byte-identical output.

```sh
python3 main.py
cat /output/entry.txt
```
